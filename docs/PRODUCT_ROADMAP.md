# GEO Lens product roadmap

This roadmap turns the MVP into a serious SEO/GEO/marketing workflow tool.

---

## Current MVP

The current version is a local-first Chrome extension with:

- Side panel report.
- On-page highlighting.
- Section grades.
- SEO fundamentals.
- JSON-LD detection.
- GEO scoring.
- BYOB LLM prompt.
- Markdown/JSON export.
- First-time walkthrough.
- Local settings.

---

## Phase 1: Make the MVP robust

### 1. Better section extraction

Add support for:

- Shadow DOM.
- Iframes where allowed.
- SPA hydration timing.
- Article extraction fallback.
- Visual section grouping by bounding boxes.
- Better heading hierarchy trees.

### 2. Better evidence extraction

Add detectors for:

- Definitions.
- FAQs.
- Tables.
- Step-by-step instructions.
- Comparisons.
- Pros/cons.
- Source links.
- Author/reviewer blocks.
- Last-updated dates.
- Policy/security claims.
- Product specs.

### 3. Better user controls

Add:

- Custom intent phrase dictionaries.
- Vertical presets: SaaS, ecommerce, local business, crypto/security, healthcare, legal, documentation, news.
- Ignore list for false positives.
- Export/import settings.
- Dark mode.
- Keyboard shortcut help.

### 4. Better reporting

Add:

- One-page executive summary.
- Editor checklist.
- Developer checklist.
- Schema recommendations.
- Content rewrite brief.
- Before/after score simulation.

---

## Phase 2: Professional workflow

### Team-friendly exports

Add exports for:

- Google Docs brief.
- Notion-ready Markdown.
- Jira ticket format.
- Asana task format.
- CSV of issues.
- Screenshot with highlights.

### BYOB prompt templates

Add prompt modes:

- Content rewrite.
- Schema recommendation.
- SEO technical QA.
- Product page optimization.
- Blog refresh.
- FAQ expansion.
- Competitive page comparison.
- Legal/compliance claim review.
- Executive summary.

### Saved reports

Add local report history:

- Last 20 audits.
- Compare latest vs previous.
- Export all reports.
- Delete report history.

---

## Phase 3: Optional backend

Only add a backend when local-first limits become painful.

Backend-worthy features:

- Multi-page crawl.
- Scheduled monitoring.
- Team workspaces.
- Shared reports.
- Report comments.
- Competitor tracking.
- Search Console integrations.
- Lighthouse/PageSpeed server-side runs.
- Large-scale schema validation.

Keep BYOB as the default even if backend features exist.

## Strong product position

Do not become another SEO checklist extension.

The differentiated promise should be:

```text
GEO Lens shows exactly where a page is easy or hard for answer engines to understand, cite, and use.
```

Everything should reinforce that.
